# 📝 To-Do List

A simple and user-friendly To-Do List web application built as a web development project.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Tasks are stored using Local Storage

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Purpose

This project was created to practice front-end web development and JavaScript concepts.

## 🚀 Future Improvements

- Add task categories
- Add due dates
- Add dark mode
- Improve mobile responsiveness
